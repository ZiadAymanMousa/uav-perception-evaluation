# Saved-output size and error analysis, version1

17 October2026, choices fixed before this analysis's dataset results. This is exploratory development analysis after the aggregate scores were inspected, not a preregistration or final-test experiment.

Question: which annotated original-size objects are matched or missed by the four existing seed0 inference settings? Use only the immutable d001 final predictions and all38,759 converted validation targets. Match all scored targets first, then group by **original integer annotation width × height** into `(0,256)`, `[256,1024)`, `[1024,9216)` and `[9216,infinity)` pixel-squared bins. These are diagnostic bins, not official size-conditioned AP.

Primary: confidence≥0.25 and IoU≥0.50. Secondary controls: all saved predictions atIoU≥0.50, and confidence≥0.25 atIoU≥0.75. Same choices for all methods; no threshold tuning. The confidence value is a declared diagnostic convention, not calibrated operational confidence. All saved predictions are already constrained by original confidence floors, NMS and caps.

Reconstruct source-line/converted-row correspondence with hash checks, the recorded conversion/serialization and exact float32 label equality. Current validation has zero clipping/duplicates; fail rather than guess if that changes. Match using existing converted coordinates; use integer source area only for grouping. Extract exact target/prediction pairs from the pinned non-SciPy rule and check TP flags against the unchanged framework at every image/method/operating point. Rematch each filtered set; do not assume a general matcher is invariant to confidence filtering. Controls must reflect the actual pinned ordering, not an invented generic-IoU scenario.

Save GT catalogue, per-image eligible/matched saved ranks and target indices, global predictionTP/FP/precision, per-bin/per-class matched/total/missed counts and micro/equal-class recalls. Keep all six paired method contrasts (`both`, `A_only`, `B_only`, `neither`) for every operating point/bin. They must reconcile exactly with the recall differences. Do not assign a GT size to unmatched predictions, infer causality from cap saturation, or call these counts a selector's recoverable utility. No bootstrap/significance/policy/flight claim. Full-548 exact native verification is a separate process and does not automatically validate this converted-task analysis.

Use meaningful controls for area boundaries, correct large objects retained during small-bin reporting, duplicate/wrong-class/empty predictions and crowded GT. Preserve failures and source snapshots. No detector, training modification, new GPU inference, annotation or paid compute. Read [the result summary](RESULTS.md) beside this plan. Future across-seed/final evaluation is separate.
